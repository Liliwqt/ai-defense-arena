# Ticket 05 — clarification, probes and alternate turns

Date: 2026-10-21. User-approved comparison point: `0388fc4`.
Local implementation complete; ready-for-human with 8/8 acceptance checks.

## Result

New Standard probe replies now use the same combined interpretation/planning
contract as normal accepted answers. The outgoing reviewer considers the original
answer plus the attributed reply, then the selected next reviewer writes the
question. Resolving a prospective reply uses the existing domain operation on a
detached session. Original text, original speaker, reply speaker/seat and separate
input provenance survive; a pending reply does not resolve live state merely by
being included in a request.

The resulting validated plan binds to the accepted complete exchange. A failed
writer retries only writing; it cannot re-interpret the original answer or erase
either contribution. Clarification and probe decisions remain on the current
question and cannot carry a next-turn assessment/selection. Invalid decisions
retain private pending input without advancing coverage or changing run charges.
Dispatched provider usage is still accounted, including rejected output.

Direct/saved replies, recovery that retains only the original answer, expired
probes, unanswered turns and openings keep separate validated planning when no
combined result exists. Superseding direct submissions invalidate pending combined
work. Existing deadline/pause accounting, eligibility, opening-history acceptance,
source/profile separation, language intent, reactions, coaching and financial
settlement retain their owners. Legacy and Free policies remain compatible.

No reviewer models, reasoning settings, prices or timer lengths changed. Typed
Streamlit optimization and focused evidence remain later tickets.
