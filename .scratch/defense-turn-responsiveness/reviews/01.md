## Spec

Independent Spec reviewer: six confirmed **P2** findings; no scope creep found.

1. **Operation starts are not broadcast.** Question generation and submission
   interpretation initialize operations without increasing the revision and
   publishing before awaiting inference. Connected clients receive the initial
   generating/interpreting snapshot with operation null; a direct/reconnecting
   view contains the newly initialized operation. Generic animation still works
   through phase fallback, but elapsed anchors differ. This misses “Expose
   authoritative operation identity/timing through compatible snapshots” and
   “reconnect/navigation reflect the existing operation.” Controlled coordinator
   probes reproduced both paths with blocked mocked AI.
   [Question work](/home/jhonryl-pamaybay/IBM-BOB/backend/rooms/questions.py:67),
   [interpretation work](/home/jhonryl-pamaybay/IBM-BOB/backend/rooms/submissions.py:105).

2. **Normal startup discards timing records.** The default sink emits INFO on a
   logger with no logging configuration. Importing the server and applying
   standard Uvicorn logging yields effective WARNING, INFO disabled and no root
   handlers. Thus ordinary documented startup does not capture these records,
   missing “Capture complete/stage elapsed time.” Configure an intentional sink
   and verify it through normal startup instead of only installing a test sink.
   [Default timing sink](/home/jhonryl-pamaybay/IBM-BOB/backend/room_operations.py:39).

3. **Supplied usage never reaches measurements.** The timing API accepts usage,
   but every runtime completion call omits it; actual provider callbacks only
   reconcile the allowance. The allowlist unit test passes manually supplied
   fields, so it does not establish integration. Available token/reasoning/model/
   provider/cost data is absent even when supplied, missing “Capture … available
   supplied usage.” Preserve unavailable values as unknown while wiring actual
   safe supplied metadata through the real request path.
   [Operation completion](/home/jhonryl-pamaybay/IBM-BOB/backend/rooms/model.py:127),
   [provider usage callback](/home/jhonryl-pamaybay/IBM-BOB/backend/openrouter_questions.py:348).

4. **Automatic backoff appears as active generation.** The retry path publishes
   a retry operation, then sleeps one second. Its presentation always says active
   generation with retryWait false, and the delay is folded into generation
   timing. This misses “distinguish … retry wait from work” and separate retry
   overhead. Expose the actual wait phase and resume active generation when the
   retry request starts, without changing existing retry rules in ticket 01.
   [Retry sleep](/home/jhonryl-pamaybay/IBM-BOB/backend/rooms/questions.py:146),
   [retry label](/home/jhonryl-pamaybay/IBM-BOB/game/src/lib/roomPresentation.ts:64).

5. **Coaching timing excludes durable completion.** Completion samples its end
   time before validation and durable finish_run, then uses that older value for
   stage/total completion. A controlled probe of the actual progressive
   completion function advanced mocked storage time by seven seconds; both
   recorded durations were zero. This misses “Capture complete/stage elapsed
   time.” Section exception classes are also discarded and later represented by
   the aggregate IncompleteSections class. Capture actual completion timing and
   available section failure classes without logging exception messages/content.
   [Completion timing](/home/jhonryl-pamaybay/IBM-BOB/backend/rooms/coaching.py:212).

6. **The baseline/replay harness cannot execute comparable defenses.** Replay
   only summarizes supplied JSONL records; comparison groups arbitrary records.
   There is no synthetic source/answer runner or case/conditions identity linking
   baseline and candidate executions. “Establish the comparable baseline/replay
   harness with synthetic sources/answers” is only partially delivered. Connect
   synthetic cases to the actual workflow and emitted timing records, retaining
   reproducible case/condition metadata without private content. Real inference
   quality and model selection remain ticket 08 work.
   [Replay harness](/home/jhonryl-pamaybay/IBM-BOB/tests/operation_timing_harness.py:119).
