- **The pypdf reading-order constraint is now written down, 2026-10-01.** The user reported that a cited line "wasn't on the PDF"; it was. `pypdf` reads a page's content stream, which is draw order rather than visual position, so in a slide deck a line numbered 16 on page 6 sat somewhere the user did not visually associate with it. The cited text is always genuinely in the upload, because `_ground_question` looks the excerpt up in the server's extracted lines and refuses the question when the lookup misses. `README.md` records this so a reviewer who hits the same surprise does not conclude the app hallucinated a citation.
