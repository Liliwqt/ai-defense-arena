## Transport, capability and spend constraints

OpenRouter documents a stateless **`POST https://openrouter.ai/api/v1/responses`**, including streaming: `store:true` and non-null `previous_response_id` are rejected. The app already uses OpenAI SDK `responses.parse`/`responses.stream`, Pydantic models and `store:false`; compatibility is plausible but must be checked for actual SDK parse events, partial mapping JSON, refusal/truncation/errors and each exact schema. OpenRouter's structured-output guide documents schema output with streaming; valid JSON alone is insufficient for citation/coverage correctness. [Fetched Responses overview](https://openrouter.ai/docs/api_reference/responses/overview), [structured outputs](https://openrouter.ai/docs/guides/features/structured-outputs).

For text requests, require parameter support (`provider.require_parameters:true`), retain local Pydantic and source-reference validation, and constrain providers/fallbacks to the tested schema/privacy/context set. Apply per-token `provider.max_price` caps, explicit output/reasoning ceilings and an account/key spend cap; `max_price` filters route rates, not total run spend. `provider.zdr:true` and `data_collection:"deny"` are documented text routing controls, but exact endpoint eligibility and account settings still need confirmation. Disable content logging/Broadcast and unnecessary plugins for private papers; ZDR is not a blanket promise covering application logs, tools or processing region. [Provider routing](https://openrouter.ai/docs/guides/routing/provider-selection), [ZDR scope](https://openrouter.ai/blog/insights/zero-data-retention/).

Choose explicit paid IDs, not `:free`, `openrouter/free`, automatic model routing or moving `latest` aliases for a predictable purchased defense. Free models have availability/context differences and limits of 20 requests/minute and 50/day, rising to 1,000/day after $10 credit purchases. Paid routes still have provider rate limits. Funding/platform fees are separate from model token rates. [OpenRouter pricing](https://openrouter.ai/pricing), [free-model caveats](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/).

Cost the whole run: mapping, repeated paper/history input, reviewer moves, submission interpretation, clarification/probes, coaching batches, retries and reasoning tokens, plus speech and funding fees. Cache reuse depends on the same model/provider/conversation; four models do not share one cache, and failover can lose reuse. Treat caching as measured upside rather than a guaranteed discount. [Prompt caching](https://openrouter.ai/docs/guides/best-practices/prompt-caching).

Local source constraint: `backend/question_generator.py::generate_research_move` currently chooses the reviewer/topic/question and assesses previous coverage in one request; after the opening reviewer sequence, eligible options can contain multiple reviewers. A caller cannot route that call by the reviewer it has not selected yet. A future design must select an eligible reviewer before generation or deliberately introduce another bounded selection call, preserving coverage and retry rules. No such change is implemented here.

## Speech: OpenRouter is not a verified Realtime replacement

Current code (`backend/speech_provider.py`, `backend/rooms/speech.py`) connects directly to OpenAI Realtime transcription over WebSocket, forwards 24kHz PCM, uses manual finalization and server deadlines/allowance, and stores no application audio archive. Text migration does not remove that dependency.

OpenRouter's current **`POST /api/v1/audio/transcriptions`** accepts base64 JSON, multipart upload or provider-downloaded URL and returns completed transcription JSON; the API reference does not document a streaming/WebSocket session contract. `verbose_json` can return word/segment timestamps when supported, and language hints use ISO-639-1. Model/provider features can fail with 400. Names containing “streaming” describe model capabilities, not proof of an OpenRouter live socket endpoint. The October ElevenLabs announcement expressly excludes Realtime Scribe v2 over WebSocket. [Current STT API reference](https://openrouter.ai/docs/api/api-reference/stt/create-transcription), [ElevenLabs launch](https://openrouter.ai/blog/announcements/elevenlabs-on-openrouter/).

These are arithmetic illustrations for 600 non-overlapping billed seconds, excluding retries, minimum charges/options, platform fees and provider price variation; they are not observed bills. No English/Filipino/Cebuano/code-switching quality or filler/pause measurement has been verified. Scribe is the initial non-OpenAI-model candidate to evaluate if its language support, privacy and price fit; Whisper Turbo is the cost comparison if OpenAI-origin weights are acceptable.

**Documentation conflict matters for privacy and limits.** The July tutorial says chat `order`, `only`, `allow_fallbacks`, `data_collection` and `sort` are not applied to transcription, with no URLs and a 60-second upstream processing timeout. The current API reference now explicitly advertises transcription `provider.zdr`/`data_collection` and URLs; October's ElevenLabs guide gives a 180-second upstream timeout. Prefer the current reference for the advertised contract, but obtain endpoint/account confirmation and a fail-closed test before claiming retention enforcement. Do not copy chat routing settings and declare speech ZDR verified. Multipart's documented 25MB limit is separate from audio duration and upstream processing timeout. [Older tutorial](https://openrouter.ai/blog/tutorials/transcription-on-openrouter/), [current reference](https://openrouter.ai/docs/api/api-reference/stt/create-transcription), [newer provider-specific guide](https://openrouter.ai/blog/announcements/elevenlabs-on-openrouter/).

A complete OpenRouter-only migration therefore needs an approved speech behavior/transport design. File-at-Send transcription would remove live draft captions; chunked requests require bounded buffering, sequence/deduplication, retry accounting, late-result rejection, temporary audio deletion and turn/speaker provenance. Both must preserve manual Send/finalizingSend, deadline fences, the shared ten-minute allowance, typed fallback and no audio archive. A file endpoint cannot silently replace the live protocol. Keep voice disabled until real protocol, privacy, cost, multilingual recognition and native/hosted capture evidence exists, or explicitly choose a different live STT transport if preserving live captions cannot be met through OpenRouter.

## Evidence required before selecting a tier

Use consented synthetic research fixtures across empirical, theoretical and mixed approaches and multiple fields; include nonparticipant ethics, contradictory/missing evidence, long papers and language switching. Compare exact citation validity, schema failures/retries, role relevance, coverage progression, hallucination/invention, helpful coaching and p50/p95 latency/cost against the same baseline. Preserve existing deterministic citation/authorization/deadline checks. Offline mocked gates test implementation contracts; they cannot establish model or recognition quality. Retail tier prices should follow measured run costs and quality, not advertised token prices alone.
